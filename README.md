# ICG 荧光胸腔镜边界识别

吲哚菁绿(Indocyanine Green, ICG)荧光胸腔镜图像的自动边界识别 / 分割,辅助肺段间平面界定。

## 项目目标

- **初期目标(11 月)**:完成图像分割 baseline 模型 + 项目申报书
- **技术路线**:胸腔镜 ICG 图像 → 边界标注 → 训练分割模型 → 输出边界线 → 临床评估
