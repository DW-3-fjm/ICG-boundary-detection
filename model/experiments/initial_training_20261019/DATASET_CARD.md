# 初次训练数据集说明

## 数据是否在 GitHub

**原始医疗数据不在 GitHub，也不应上传到公开或私有仓库。** 这是根 README 与《提交规则》的明确约定。本目录公开代码、匿名样本序号、来源组划分、汇总及逐图数值，原图、LabelMe JSON、多边形坐标、mask、私有文件对应表、视频、预测图和权重仍在本地或由团队线下交接。

仅克隆仓库无法直接复现真实图片训练，需要取得对应的本地数据。仓库没有虚构下载链接或把合成图片标为临床数据。

## 数据规模与标签语义

| 阶段 | 图片数 | 含义 | 本轮用途 |
|---|---:|---|---|
| Q | 5 | ICG 显像前的目标区域 | 保留作后续辅助实验 |
| Z | 25 | ICG 显像中的目标区域 | 主任务，15/5/5 划分 |
| H | 20 | ICG 显像后的目标区域 | 保留作后续辅助实验 |
| L | 5 | 器械标注 | 独立保留，不作为目标为空的负样本 |

共 55 张 PNG 和 55 份 LabelMe JSON。Q/Z/H 是阶段标签，模型仍为目标/背景两类分割。前景为现有多边形内部的并集，背景为其他像素；不按绿色区域翻转内外。统计是图片数，不是多边形数量。

历史图像为 3840×2160、8 位三通道。训练保持 16:9 比例，缩放至 512×288，mask 用最近邻插值。多边形栅格化沿用已有 LabelMe 转换器；不读取标注覆盖图作为输入 mask。

## 来源组与固定划分

`split_manifest.csv` 是匿名实验清单，字段为 `filename,phase,source_batch,split`。它没有患者姓名、原始文件夹名、标注坐标或可访问患者数据的链接。

| 来源组 | 集合 | 匿名文件序号 |
|---|---|---|
| batch_02 | 测试 | sample_00006 至 sample_00010 |
| batch_04 | 验证 | sample_00016 至 sample_00020 |
| batch_05 | 训练 | sample_00021 至 sample_00025 |
| batch_07 | 训练 | sample_00031 至 sample_00035 |
| batch_09 | 训练 | sample_00041 至 sample_00045 |

组来自私有转换映射中的来源文件夹，并经全部 Z 原图外观检查。组内整体保留；seed=42 的 3/1/1 整组分配在训练前冻结，未按旧模型分数挑样本。像素检查未发现完全重复。跨集合原图 SSIM 最大约 0.474，ORB 仿射内点最多 6，仅作为外观核对，不能证明患者独立或时间独立。

按用户此前说明，全部数据保守归为同一患者。来源组不能当作患者身份。Q/H 未经对应关系确认不得混入训练，尤其不能加入与验证或测试画面关联的辅助帧。

## 线下交接所需内容

1. 保持原目录结构的 55 份 LabelMe JSON 和对应源图，或既有 `fullres/train/images` 与 `fullres/train/masks`。
2. 私有 `conversion.private.json` 或经团队核对的原文件至匿名序号对应表。公开清单本身无法还原原文件身份。
3. 标注含义、器械/遮挡处理和有效组织分界段的规则。若新增数据，再提供私有患者/手术分组，重新冻结划分。
4. 若仅核对历史预测，另交接本轮 `best_model.pt`；从零训练不需要旧权重。

原始目录排序或文件名改变会影响匿名编号。数据准备工具会核对 Z 阶段覆盖、来源组、图像/mask 配对及重复；出现不匹配应先查线下映射，不应重命名患者数据来迁就结果。新建转换、训练和输出目录，保留既有实验记录。

## 评价范围

本轮是静态二值区域及外轮廓评价，区域轮廓可能包含画面裁切边。没有毫米标定，没有独立患者测试，没有完整荧光消退视频，也没有连续帧独立参考边界。不能由这些图片评价动态保持时间、漂移恢复或临床安全性。后续外部测试应使用新的患者和连续视频。
