# 数据集登记与本地接收约定

本次实际使用的匿名划分共94张有标注帧。它不是94位患者，也不是新增94个独立病例。

|患者代号|用途|帧数|阶段|
|---|---|---:|---|
|patient_001|训练|20|Z|
|patient_001|内部验证|5|Z|
|patient_002|主测试|25|Z12 + Z且L13|
|patient_002|预设辅助测试|44|Q17 + H10 + 未确认阶段L17|

本地私有目录建议仍沿用`model/data/cross_patient_20261022_01`。仓库只登记位置和匿名清单，不包含数据或下载链接。详细身份映射由数据负责人私下保存。患者二另有1张未标注图片，未纳入本轮研究。

```text
cross_patient_20261022_01/
  fullres/train/images/    fullres/train/masks/   # 20对
  fullres/val/images/      fullres/val/masks/     # 5对
  fullres/test/images/     fullres/test/masks/    # 69对，其中主测试25对
  resized/train/images/   resized/train/masks/   # 20对，512×288
  resized/val/images/     resized/val/masks/     # 5对，512×288
```

目录中的文件名必须与`split_manifest.csv`的匿名ID一致。原图为3840×2160；训练图用INTER_AREA缩放，mask用INTER_NEAREST；二值mask中0是背景、非0是目标。原多边形合并为内部区域，顶点四舍五入到像素、裁剪到画面内并填充，不反转颜色，不把L转换成器械mask。

标签Q、Z、H记录阶段，L记录器械遮挡下目标区域。只有用户确认处于Z阶段的13张L进入主测试，其余L不得自行推断阶段。数据纳入表和分组已冻结，不能按预测分数决定纳入或剔除。

`source_group`是来源文件夹分组，不是患者/手术数量，也不是经视频时间戳证实的时间片段。源文件夹隔离仅用于降低开发集近邻泄漏，不能据此断言相邻帧已完全排除。协议检测了相同解码像素的完全重复；近重复和帧间相关性仍需额外审查。

接收方应先用获授权的私有映射准备配对目录，再通过`prepare-replay`检查文件和开发集SHA256；最终测试阶段才读取测试内容并检查其SHA256。协议中`files`保留每个私有数据文件的相对路径及哈希，足以发现误换图像、mask或划分，但无法代替原始数据本身。

新增患者必须另建数据版本和研究目录，保留患者、手术和片段标识；不同患者不跨开发/最终测试。未来正式比较需加入独立患者测试及完整时序数据，不能把此次已查看测试集继续当作未知盲测集。
